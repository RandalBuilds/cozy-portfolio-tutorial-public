# Mascot

Dumpling, the guide duck: a round little honey-yellow duckling who greets visitors, gives hints and reacts to clicks. Five moods: `idle` (breathing, tail wiggle), `wave` (wing wave), `happy` (hop), `sleepy` (z z), `talking` (beak flaps, for dialogue portraits).

**Consumer provides:** `mood`, `size` (px, default 120), optional `label` (default "Dumpling the duck, <mood>"). Built from tokens — `honey-400` feathers, `terracotta-500` beak and feet, `cream-50` belly, `cocoa-900` outline — so it re-themes. Reduced motion freezes it.

- Do: use Dumpling as the only character guide; one appearance per screen.
- Don't: recolour the duck outside the token palette or give it a black outline.
